# Code of Conduct

We want this to be a welcoming project for everyone. A few basic rules:

**Be respectful.** Disagreements happen but keep it civil. No personal attacks, no harassment, no hate speech.

**Be honest.** If you're submitting attraction data or reviews, make sure it's accurate. Don't add fake listings or misleading info.

**Be patient.** Not everyone has the same level of experience. Help newcomers instead of dismissing them.

**Stay on topic.** Keep issues and PRs focused on the project.

---

If someone is being a problem, email xenohuru@gmail.com. We'll look into it.

Repeated violations can lead to being removed from the project.
